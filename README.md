# Personal Portal & Live Clock

A sleek, responsive personal dashboard featuring real-time clock updates, time-of-day greetings, customizable identity, and multi-theme support with glassmorphism aesthetics.

## Features

- **Live Real-Time Clock**: High-precision ticking clock displaying HH:MM:SS with 12H/24H mode toggle.
- **Dynamic Greeting**: Time-aware greeting tailored to the time of day and your personalized name.
- **Personalized Profile**: Customizable name, role, and avatar monogram with instant local persistence (`localStorage`).
- **Interactive Work Status**: Status pill with cycling status modes.
- **4 Color Themes**: Obsidian Glow (default), Cyber Violet, Aurora Emerald, and Twilight Sunset.
- **Daily Focus & Quick Links**: Editable daily focus thought and direct links to GitHub and Contact.

## Getting Started

Simply open `index.html` in any modern web browser or serve locally using any static web server:

```bash
python -m http.server 8080
```
